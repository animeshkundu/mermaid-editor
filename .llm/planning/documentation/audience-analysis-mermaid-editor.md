# Audience Analysis: Mermaid Editor Documentation

## Primary Audience: Contributors & Developers
* **Who**: Software engineers looking to contribute to the Mermaid Editor project or maintain it.
* **Prior Knowledge**: React, TypeScript, Vite, basic Mermaid syntax.
* **Knowledge Gaps**: Project-specific architecture, state management (URL/LocalStorage), export logic, testing patterns.
* **Goals**: Fix bugs, add features, improve UI, ensure stability.
* **Pain Points**: Understanding the complex export logic (SVG to Canvas), how state is persisted, and how to write proper tests for canvas/mermaid.

## Secondary Audience: Power Users / Integrators
* **Who**: Users who want to understand how the editor works under the hood or integrate parts of it.
* **Goals**: Understand the data flow and export capabilities.

## Anti-Audience
* **End Users**: People who just want to *use* the editor (they need a User Guide, not these technical docs).
